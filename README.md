# Telegrambotchat
# 🤖 ربات چت ناشناس تلگرام (Anonymous Telegram Chat Bot)

یک ربات چت ناشناس تلگرام نوشته شده با **Python** و کتابخانه **pyTelegramBotAPI**، آماده برای استقرار (Deploy) رایگان و آنی روی **Railway**.

---

## ✨ امکانات ربات

- 🔄 **اتصال خودکار:** متصل کردن دو کاربر در صف انتظار به یکدیگر.
- 💬 **پشتیبانی از انواع پیام‌ها:** ارسال متن، عکس، ویس، استیکر و ویدیو.
- 👑 **پنل مدیریت (Admin Panel):**
  - مشاهده آمار کامل ربات (`/stats`)
  - ارسال پیام همگانی به تمام کاربران (`/broadcast`)
  - بن و آن‌بن کردن کاربران متخلف (`/ban` و `/unban`)
- 🔒 **امپلیت امنیت:** عدم ذخیره‌سازی توکن و آیدی ادمین در کد اصلی (استفاده از متغیرهای محیطی).

---

## 🛠️ پیش‌نیازها و فایل‌های پروژه

- `main.py` - کد اصلی ربات
- `requirements.txt` - کتابخانه‌های مورد نیاز پایتون
- `Procfile` - دستور اجرای پروژه روی Railway
- `README.md` - راهنمای پروژه

---

## 🚀 راهنمای نصب و راه‌اندازی روی Railway

1. این پروژه/ریپازیتوری را در حساب **GitHub** خود آپلود کنید.
2. وارد سایت **[Railway.app](https://railway.app)** شوید و با حساب گیت‌هاب خود وارد شوید.
3. یک **New Project** بسازید و ریپازیتوری مربوطه را انتخاب کنید.
4. به تب **Variables** بروید و ۲ متغیر زیر را اضافه کنید:

| نام متغیر (Key) | توضیحات (Value) |
| :--- | :--- |
| `BOT_TOKEN` | توکن دریافت شده از BotFather@ |
| `ADMIN_ID` | آیدی عددی تلگرام ادمین (دریافت از userinfobot@) |

5. پروژه به‌صورت خودکار Build شده و روشن می‌شود!

## 📝 دستورات ربات

### کاربران عادی:
- `/start` - شروع کار با ربات
- `/search` - جستجوی هم‌صحبت
- `/stop` - پایان چت یا خروج از صف

### ادمین:
- `/admin` - راهنمای پنل ادمین
- `/stats` - مشاهده آمار ربات
- `/broadcast متن` - ارسال پیام همگانی
- `/ban user_id` - مسدود کردن کاربر
- `/unban user_id` - رفع مسدودی کاربر
